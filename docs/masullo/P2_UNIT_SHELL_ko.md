# 소수 2의 단위 껍질에서 주값이 하는 일

## 원문에서 확인한 조건

Masullo의 고정 원고 519쪽 식 (12.5.1.2)는 유한 장소에서 국소 주값을 사용한다. 622쪽 보조정리 B.4.4.5는 단위군 안에서 $f(u)-f(1)$을 적분하도록 정의한다. 원고의 623쪽 주석과 같이 $f$가 국소 상수이면 이 차는 1의 충분히 작은 근방에서 0이다. $F_v=\mathbb Q_2$에서는 국소 different가 자명하다. [원고와 SHA-256](README_ko.md)

$U=\mathbb Z_2^\times$에 대해 곱셈 Haar 측도를 $\nu(U)=1$로 놓는다. 단위 껍질에서는 $|u|_2^{1/2}=1$이므로, 주값의 단위 부분을 $\log 2$로 나눈 값은

$$
\int_U \frac{f(u)-f(1)}{|1-u|_2}\,d\nu(u).
$$

원고의 12.5.1.1은 $\varphi|_{C_F^1}=0$을 가정한다. 국소 단위의 이델류는 노름 1이므로, 이 가정 아래에서 $U$에 제한된 원고의 시험 함수는 전부 0이고 단위 부분도 0이다. 국소적으로 $f(1)=0$만 주어지면 주값의 뺄셈이 사라지지만 단위 부분은 남을 수 있다. 예를 들어 $f=\mathbf 1_{3+4\mathbb Z_2}$이면 그 값은 $\log 2$다. 해당 합동류의 Haar 질량 $1/2$에 역노름 $2$가 곱해진다.

## 분기 문자에서 도체 지수가 나타나는 이유

국소 대조 입력으로 $f=\mathbf 1_U\chi$를 택한다. 여기서 $\chi$는 $U$의 비자명한 연속 문자이고, $a$는 $\chi$가 $U_a=1+2^a\mathbb Z_2$에서 자명해지는 최소 지수다. 이 입력에서는 $f(1)=1$이다.

각 $r\ge1$에 대해 $v_2(1-u)=r$인 단위를 $U_r\setminus U_{r+1}$로 쓴다. $\nu(U_r)=2^{1-r}$이고, 따라서 이 껍질의 질량 $2^{-r}$과 무게 $2^r$의 곱은 1이다. $U_r$에 제한된 문자가 비자명이면 Haar 평행이동 불변성으로 그 적분은 0이다. 자명하면 그 적분은 $\nu(U_r)$다.

| 껍질 | $\chi(u)-1$을 적분한 뒤 무게 $2^r$를 곱한 값 |
| --- | ---: |
| $1\le r<a-1$ | $-1$ |
| $r=a-1$ | $-2$ |
| $r\ge a$ | $0$ |

둘째 행에서 $U_{a-1}$의 문자 적분은 0이고 $U_a$의 문자 적분은 $2^{1-a}$다. 따라서 껍질의 문자 적분은 그 질량의 음수다. 합치면 주값의 단위 부분은 **$-a\log 2$**다. Mod 4 원시 문자의 경우 $a=2$이므로 $-\log 4$가 나온다.

## 정확한 합과 Euler 인자 대조

| 국소 입력 | 주값의 단위 부분을 $\log2$로 나눈 값 |
| --- | ---: |
| 단위군의 자명 문자 | $0$ |
| Mod 4 원시 문자 | $-2$ |
| Mod 8 원시 문자 $\chi(1),\chi(3),\chi(5),\chi(7)=(1,-1,-1,1)$ | $-3$ |
| $\mathbf 1_{3+4\mathbb Z_2}$ | $1$ |

정확한 합은 법 $2^N$의 홀수 합동류에 같은 질량을 주고, 1의 합동류를 제외해 계산한다. $N=3,\ldots,10$에서 위 결과를 확인했다. Mod 4 원시 문자는 단위군에서 평균이 0이지만, $f(1)$을 빼지 않은 가중합은 $N-3$이었다. 가중치가 단위 변수에 따라 달라지기 때문이다. [유리수 대조 코드](../../tools/prime_two_unit_shell.py)

~~~sh
python -E -S tools/prime_two_unit_shell.py
~~~

2026-11-24 Colab Linux의 Python 3.13.18에서 국소 입력 5개와 절단 깊이 8개를 다시 계산했다. 위 표의 네 입력과 노름 1 소멸 조건을 반영한 영함수 대조 입력이 모두 Windows 기준과 일치했다. 출력 SHA-256은 `86d486239a64eec975e9dd2d41f866f1e377b51630de8c0332138488768b1c1c`다. [실행 입력과 범위](../ROADMAP_ko.md#단계-전환-때-재현)

Alpöge 쪽 레벨 계산에서 Mod 4 원시 문자와 Mod 4 주문자는 모두 $L_2(s)=1$이다. 단위군에 제한하면 앞의 문자는 도체 지수 2인 비자명 문자이고, 뒤의 문자는 자명하다. 위 국소 대조 입력은 각각 $-\log4$와 0을 준다. 원고의 전역 시험 함수 조건, 단위 밖 껍질과 Mellin 정규화까지 연결해야 식 (12.5.1.2) 전체와 Euler 인자를 비교할 수 있다. [레벨과 도체 대조](P2_CHARACTER_COMPARISON_ko.md)
