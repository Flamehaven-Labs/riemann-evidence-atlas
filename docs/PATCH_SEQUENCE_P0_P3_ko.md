**로컬 대조 통과, 원본 확장 일부 보류.** BFS 합류 회귀, v2 선언 매치와 긴 tar 경로 회귀를 통과했다. 두 보조 증명의 직접 참조 57개 중 53개를 Lean `Init`에서, 나머지 네 개를 고정 Mathlib에서 확인했다. [Mathlib 후속 대조](rh-mathlib-frontier-match.json) 첫 Colab은 공개 커밋을 고정한 뒤 합성 Lean과 Python 재현을 수행하고, 고정 원본을 준비한 세션에만 원본 대조를 추가한다. [실행 순서와 결과](LEAN_MATCH_AND_COLAB_ko.md)

- [x] **P1.1 확보한 보조 증명의 직접 참조 대조.** `rh_of_right._proof_1_1`, `rh_of_right._proof_1_2`의 이미 추출된 참조 목록에서 중복을 제거하되 각 참조의 출발점은 보존한다. 두 57개 직접 참조 집합은 동일하며 `Lean.Omega.*`를 포함한다. 후속 패스는 중복 57개를 한 번 분류해 두 출발점에 연결한다. 직접 `Classical.choice`는 관측되지 않았고 전이 여부는 열린 상태다. 같은 `.olean`에 있거나 고정 Lean의 좁은 모듈 묶음으로 읽을 수 있는 선언을 우선한다. 각 항목에 소속 모듈, 선언 종류, TYPE 또는 VALUE 간선, 직접 확인 여부를 기록한다.

## P2 — 두 연구의 공통 국소 항 검증

**유리수 계산 GREEN · 원문 분석 연결 HELD.** 소수 2의 네 문자 사례와 잘못된 부호·분기 인자·도체를 거부하는 회귀 검사를 기준선 실행에 연결했다. 고정 원고 514·519–520·522쪽과 `ClaimStrip`의 전제를 대조했으며 주값–Euler 인자 대응은 P3.2의 열린 과제로 남긴다. [실행 결과와 원문 위치](masullo/P2_CHARACTER_COMPARISON_ko.md)

- [x] **P2.1 원문 항 하나를 고정.** $F=\mathbb{Q},\ p=2$에서 Masullo 519쪽의 유한 장소 항 (12.5.1.2)을 출발점으로 삼는다. Alpöge 쪽에서 비교할 소수 거듭제곱 가중식의 실제 소스 또는 Lean 선언을 찾는다. 양쪽에 각각 위치, 변수, 문자 인자, conductor와 modulus, 분기 시 인자 처리, 측도·로그 정규화를 기록한다. 한쪽 위치나 적용 전제를 확인하지 못하면 원문 대응은 보류하고 순수 산술 재현은 별도로 보고한다.
- [x] **P2.2 $s=2$의 정확 유리수 대조를 추가.** $L_2(s)=(1-\chi(2)2^{-s})^{-1}$ 표기에서 $-L_2'(s)/(L_2(s)\log 2)$의 계수를 함께 검사한다. 도입할 대조는 자명 문자, 2에서 비분기인 modulo 3의 비자명 문자, 2에서 분기하는 primitive modulo 4 문자와 modulo 4 비원시 주문자다. Alpöge 쪽 후보는 `ClaimStrip.lean`의 `prim_zero`와 `LFunction_changeLevel`이다.

  | 대조 | $L_2(2)$ | 로그미분 계수 |
  | --- | ---: | ---: |
  | 자명 문자 | $4/3$ | $1/3$ |
  | modulo 3 비자명 문자, $\chi(2)=-1$ | $4/5$ | $-1/5$ |
  | modulo 4 primitive 문자, 2에서 분기 | $1$ | $0$ |
  | modulo 4 비원시 주문자 | $1$ (modulus 4), $4/3$ (도체 1의 원시 문자) | $0$ (modulus 4), $1/3$ (도체 1) |

  문자 부호를 뒤집거나 2에서 분기하는 경우에 유한 Euler 인자를 잘못 넣은 입력을 기각한다. 일반 소수 입력으로 인터페이스를 넓히는 경우에만 소수성 검사를 추가한다. 현재 파일럿의 $p=2$ 입력과 보고서는 유지한다.
- [x] **P2.3 필요한 원문 전제 확인 및 보류 판정.** 514쪽 cutoff 수정 메모가 선택한 유한 장소 항의 도출에 영향을 주는지, 519쪽 $\varphi(C_F^1)=0$이 어떤 의미로 사용되는지, 520쪽 논증에서 실제로 쓰이는 부분을 좁혀 기록한다. $g_2=2^m u$에서 $m\ne0$이면 $|1-2^m u|_2=\max(1,2^{-m})$이고, $m=0$이면 모든 2진 단위에서 $|1-u|_2\le1/2$다. 분기 문자 평균 소거를 적용하기 전에 남은 가중치가 $u$에 의존하는지 검사한다. 주값 적분과의 대응은 Haar 정규화와 테스트 함수 조건을 대조한 뒤 판정한다. 외부 반론은 원문과 적용 전제가 고정되는 대로 별도 판정한다.

**완료 기준** 정확한 입력·가정·식·기각 대조를 재현하고 그 결과의 양쪽 원문 위치를 제시한다. 원문 대응을 확정할 수 없으면 계산의 확인 범위와 누락된 연결을 명시한다. 522쪽 결손 상태와 국소 검증 결과는 각각 기록한다.

**P3.1 GREEN · P3.2 HELD · P3.3 범위 한정 GREEN.** Lean 4.33.1 및 고정 Mathlib에서 두 실수 지수 구간, 꼬리 적분 등식, 128비트 포함과 두 임계값을 확인했다. Python 3.10·3.14 각각 43개 회귀 및 P0·P1의 기존 영수증 재현이 통과했다. [실행 방법 및 범위](P3_LANDAU_TAIL_ko.md) · [Lean 실행 기록](landau-tail-lean-replay.json)

- [x] **P3.1 Landau 파일럿의 해석적 간극을 닫는다.** 기존 유리수 임계값 증명을 재사용한다. 첫 목표는 고정 $k=3$, $s=3$, 창 $[1,3]$에서 실제 꼬리 적분이 저장한 유리수 구간 안에 들어가는 충분조건을 Lean에서 증명하는 것이다. 고정 꼬리는 $J_{\mathrm{tail}}=(1-13e^{-3}+172e^{-9})/81$이다. Rat 단계에서는 $3/8$과 $9/32$의 128비트 급수·외향 반올림을 검증하고 각각 3회·5회 제곱한다. 별도 실수 단계에서는 원시함수와 경계값으로 꼬리 항등식을 증명하고, 급수 포락을 실제 $\exp$에 연결한다. 계수 $-13$에는 반대쪽 구간 끝점을 사용한다. 성공 시 기존 양성·음성 임계값을 해당 실수 적분에 적용해 다시 확인한다. P2의 원문 대응이 보류돼도 Landau 단독 작업은 진행할 수 있다.
- [ ] **P3.2 `HELD` · 교차 해석 연결은 조건 충족 후 진행.** P2에서 고정한 항에 대해 Mellin–Laplace 변수변환, Haar 측도, $\varphi$의 지지·소멸 조건을 하나씩 증명한다. 유한 장소에서 global trace까지 가는 합·적분 교환과 극한은 실제 논증에 필요한 경우 별도 의무로 잡는다. 연결에 필요한 원문 정의나 결론이 빠져 있으면 해당 주장만 보류한다.
- [x] **P3.3 범위 한정 · 독립 RH 저장소에서 검증 도구의 적용 범위를 시험.** 아래 표의 공통 기능을 Alpöge의 컴파일 선언, Masullo의 원문 검토, 국소 수치 사례에 각각 적용한다. 성공 입력 외에 가정 누락, 소스 불일치, 오차로 인한 판정 불가를 시험한다. Lean 소스 컴파일, 원본 증명 항 읽기, 커널 또는 별도 검사기 실행을 개별 결과로 기록한다. 운영자나 구현이 다른 경우에만 해당 재현 수준을 부여한다.

  | 정확 유리수·구간 연산 | 기존 Landau 계산과 유한 Euler 인자의 산술 대조 | 입력 불확실성과 오차 경계가 각각 보존되는가 |
  | Lean 도구 | Alpöge의 타입·증명 항·import를 추적하고 작은 수치 증명을 검사 | 이름이 같은 정리라도 가정·정의·증명 종류의 차이를 드러내는가 |
  | 검증 실행기 | 고정 입력, 양성·음성 대조, 자원 한계에서 판정 불가를 기록 | 유효한 기각과 미실행·결측의 상태가 구별되는가 |
  | 연구 증거 관리 | 원고 버전·쪽·수식, 컴파일 파일·선언, 각 실행을 연결 | Masullo의 522쪽 결손 상태에서 국소 산술 성공이 최종 정리의 수락으로 이어지지 않는가 |

  $F=\mathbb{Q},\ p=2$의 교차 원문 대응과 Landau 적분의 형식 포함 증명은
  구별해 평가한다. 공통 코드는 이 저장소에서 독립 실행한다. 다른 도메인에
  대한 적용성은 여기서 얻은 증거를 바탕으로 후속 프로젝트에서 시험한다.

**완료 기준** 수치 기록과 원문 정의 사이의 가정 및 수학적 함의를 명확히 보존하고, 성공·기각 사례를 고정 환경에서 다시 얻는다. 전체 RH 커널 재검사, Masullo 최종 정리, 실제 과학적 효용의 판정은 각 범위의 별도 증거를 요구한다.
